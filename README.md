# 集成维护开发部组织绩效看板

> 集成绩效管理平台 — 支持总监 / 部门负责人 / 小组组长三级权限协同的绩效可视化管理系统

**3级权限 · 5部门 · 7千行代码 · 双线部署**

| 同步延迟 | 5 秒轮询 |

## 核心功能

### 1. 数据看板（Overview）

- **驾驶舱卡片**：部门绩效总览，一屏掌握全局
- **雷达图**：多维度绩效对比，直观呈现各部门强弱项
- **维度热力图**：绩效维度 × 考核周期交叉分析，支持下钻查看明细
- **排行榜**：部门绩效排名，支持按维度筛选
- **部门下钻**：点击部门名称查看该部门详细绩效数据

### 2. KPI 指标管理

- **KPI 概览卡片**：目标值 / 实际值 / 完成率一目了然
- **KPI 明细表**：支持搜索筛选，含状态标签（正常 / 预警 / 滞后）
- **Sparkline 迷你趋势图**：每个 KPI 内嵌 SVG 趋势线
- **支撑任务关联**：KPI 可关联重点工作任务，追踪执行情况
- **KPI 详情弹窗**：点击查看完整指标定义、目标、进展、关联任务

### 3. 重点工作管理

- **任务卡片视图**：按状态（进行中 / 已完成 / 延期）分类展示
- **任务详情**：含责任人、截止日期、进度百分比、更新日志
- **子任务拆解**：支持任务拆分为子任务，逐项追踪
- **过程管理**：任务趋势图 + 子任务筛选表格

### 4. 加减分项

- **加减分记录**：记录额外贡献与扣分事项
- **详情查看**：点击查看加减分依据与审批信息

### 5. 三级部门看板（L2）

- **L2 数据看板**：部门负责人视角的部门内绩效全景
- **L2 重点工作**：部门内任务管理
- **L2 数据管理**：部门数据的增删改查

### 6. 权限配置（RBAC）

- **三级权限体系**：
  - **L1 总监**：全局查看 + 全部门管理
  - **L1+L2 部门负责人**：本部门数据管理 + 权限配置
  - **L2 小组组长**：本组数据查看与编辑
- **权限配置面板**：管理员可动态配置各部门负责人与组长
- **菜单级权限控制**：根据角色动态显示/隐藏导航项（🔒 锁定标识）
- **默认管理员**：夏国晋、剡飞龙

### 7. 数据导入导出

- **Excel 导入**：支持 `.xlsx` 文件批量导入绩效数据（XLSX.js 懒加载）
- **JSON 导出**：一键导出全量数据为 JSON 备份
- **Excel 解析工具**：`excel_parser.py` 提供离线解析能力

### 8. 实时数据同步

- **5 秒轮询**：前端 `syncClient` 每 5 秒拉取服务器最新状态
- **版本控制**：每次写入递增 `version`，防止并发覆盖
- **空数据保护**：服务端拒绝用空 `stores` 覆盖已有数据
- **自动备份**：每次写入前自动备份 `data.json.bak`
- **默认数据兜底**：首次启动自动写入 `DEFAULT_STORES`，防止登录失败

### 9. 界面与交互

- **深色 / 浅色主题**：一键切换，自动持久化偏好
- **响应式布局**：适配桌面与移动端，侧边栏可折叠
- **Toast 通知**：操作反馈即时提示
- **变更日志**：记录数据修改历史

## 技术架构

```
┌─────────────────────────────────────────────┐
│              浏览器（单页应用）                │
│  dashboard_with_permissions.html (7,102行)   │
│  ┌──────────┐ ┌──────────┐ ┌──────────────┐ │
│  │ RBAC 权限 │ │ ECharts  │ │ localStorage │ │
│  │  引擎     │ │ 5.5 可视化│ │  数据持久化   │ │
│  └──────────┘ └──────────┘ └──────────────┘ │
│         │                    ↕               │
│    syncClient (5s轮询)   localStorage        │
└─────────────────────┬───────────────────────┘
                      │ HTTP REST API
                      ▼
┌─────────────────────────────────────────────┐
│           Node.js 后端 (server.js)           │
│         原生 http 模块 · 零依赖              │
│  ┌──────────┐ ┌───────────┐ ┌────────────┐  │
│  │ 静态文件  │ │ REST API  │ │ JSON 文件  │  │
│  │  托管     │ │ GET/PUT   │ │   存储     │  │
│  │  serve   │ │ /api/state│ │ data.json  │  │
│  └──────────┘ └───────────┘ └────────────┘  │
└─────────────────────────────────────────────┘
```

### 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | HTML/CSS/JS | 单文件架构，无构建步骤 |
| 可视化 | ECharts 5.5 | 雷达图 / 热力图 / 仪表盘 / KPI趋势 / 排行榜 |
| 数据解析 | XLSX.js 0.18.5 | 懒加载，按需引入 |
| 持久化 | localStorage | 离线模式数据存储 |
| 后端 | Node.js 原生 http | 零依赖，191 行代码 |
| 存储 | JSON 文件 | `data.json` + 自动备份 |
| 同步 | 5 秒轮询 | `syncClient` 增量版本检测 |

## 快速开始

### 方式一：本地服务器（推荐，全功能）

```bash
# 启动服务器

# 浏览器访问
```
